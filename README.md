# personal-portfolio
The Personal Portfolio Website is a responsive web application developed using front-end web technologies such as HTML, CSS, JavaScript, and modern UI design principles. The portfolio acts as a digital resume where visitors can learn about the developer, technical skills, projects, education, and contact details.

This project demonstrates:

-Front-End Web Development

-Responsive Website Design

-UI/UX Design

-Personal Branding

-Web Hosting and Deployment
